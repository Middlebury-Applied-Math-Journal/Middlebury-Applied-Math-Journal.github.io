# Edition template

To start a new edition, copy this folder and rename the copy to the edition's
topic without `edition-`. For example, articles tagged `edition-2027` go in
`editions/2027/`. Then fill in the copy:

| File | What it is |
| --- | --- |
| `edition.json` | The edition description, and its sections in the order they appear, each with a color. |
| `cover.jpg` | The image shown beside the edition. `.png` and `.webp` also work. |
| `closing.jpg` | The image shown after the edition's articles. |
| `editorial.md` | The editorial, written in Markdown. |

Delete this README from your copy. See "Organizing editions and sections" in
the main README.md for details.
