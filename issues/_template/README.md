# Issue template

To start a new issue, copy this folder and rename the copy to the issue's
topic without `issue-`. For example, articles tagged `issue-2027` go in
`issues/2027/`. Then fill in the copy:

| File | What it is |
| --- | --- |
| `issue.json` | The issue description, and its sections in the order they appear, each with a color. |
| `cover.jpg` | The image shown beside the issue. `.png` and `.webp` also work. |
| `closing.jpg` | The image shown after the issue's articles. |
| `editorial.md` | The editorial, written in Markdown. |

Delete this README from your copy. See "Organizing issues and sections" in
the main README.md for details.
